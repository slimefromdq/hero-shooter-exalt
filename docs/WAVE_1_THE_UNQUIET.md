# Wave 1: The Unquiet — repository audit and implementation plan

Inspected October 19, 2026. This task adds no heroes or reworks. Samson (peel/disable support), Stitch (horror melee assassin), Wisp (phantom thief, existing kit structure), and Seeker (Relay rework, offensive support with a spirit bird) are the requested direction. Detailed ability rules and numerical tuning were not supplied and are not present in the repository. The stages below identify implementation seams, not invented kit designs.

## Risks and limits

- Existing kits rely on string states and some direct state checks instead of `permits`; disables must audit active kit ticks and movement overrides as well as cast admission. A global silence flag alone will miss these paths.
- Death/reset/swap use `life_serial`; retained targets and delayed effects must not attach to a respawned life. Deferred deletion must not permit an extra hit or heal.
- Analytic hostile barriers differ from physical walls and friendly barriers. Raw world rays alone are insufficient for offensive/support LOS. Spawn doors also have a separate resolver authority check; this extraction preserves existing acquisition behavior and does not redefine that policy.
- Relay's ongoing no-LOS/no-range healing is intentional existing behavior. Doctor's obstruction grace retains selection without healing through cover. Do not unify these rules accidentally.
- Generalizing temporary health or invulnerability can change execution thresholds and existing training toggles. Prefer existing services with explicit semantics.
- Hero IDs and kit-type checks occur beyond the roster factory. Seeker migration needs a repository-wide compatibility pass; changing only the display name or only the resource path is insufficient.
- This is offline authority, not networking/prediction. Automated correctness does not establish balance, animation readability or game feel.

Samson is now implemented as the first Wave 1 hero.
